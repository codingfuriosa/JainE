JainE Database Map

Every table in the live JainE database (Supabase project rkxsgtauigjrpcjkmccu), what it holds, how big it is, and which parts of JainE use it. Read from the database on 30 Oct 2026; row counts are the database's own estimates.

What this means for speed

Most of the load comes from a handful of tables, not from size.

The data is only about 590 MB. Slowness comes from how often pages ask, not how much is stored. The busiest requests since 26 Oct were the workflow lists (acc.flow_cases, acc.flow_case_steps via wf_case_page, about 11,000 calls), the notification bell (acc.notifications, about 28,700 calls), the Tasks screen (acc.tasks and its assignees via tasks_overview, about 3,800 calls) and lead details (acc.crm_leads / acc.crm_followups). These are the tables to protect first.

65 backup copies can go.

Tables named …_backup_…, …_bak_…, bk_…, zz_…, …_removed_… or …_test are one-off copies made before past fixes. Nothing reads them. Dropping them after office hours makes the database smaller and quicker to back up. Filter by “Backups” below to see them.

Some tables are only sample data.

The public.inv_*, ast_*, con_*, cmp_*, sup_*, bud_* and fin_* tables hold about 40 example rows each, from an early demo. The real modules (Procurement, Engineering, Accounts) use their own groups. Filter by “Not used” to review them.

The big tables are history, and they are read in pieces.

The largest tables are CRM snapshots, call QA and transcripts (up to 74 MB each). They grow every day, so any new page that reads them should page through them and filter by date, never load them whole.

Groups

Each group is one area of JainE. Pick one to see only its tables.

Tables

“Used by” lists the JainE files that read or write the table directly (pages, server functions). “Database functions” counts the functions inside the database that mention it; a table can be in use through those alone. “Not used” means neither was found, which makes it a candidate for review, not proof it is safe to delete.
