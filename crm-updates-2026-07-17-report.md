## Notes for future runs

- The report page's **Refresh submit does not respond to synthetic (untrusted) JS clicks** — `input.click()` / `form.requestSubmit()` do not reload the table, so the dropdown label changes while the data table stays stale. This caused apparent "stale data" earlier in the run.
- **Reliable method used:** navigate directly to the endpoint with GET query params — `?lead[from]=YYYY-MM-DD&lead[to]=YYYY-MM-DD&project[selected]=<id>&site_executive[picked]=-1&refreshnow=Refresh`. Each navigation is a true reload; `selText` and date inputs were verified on every read to confirm the correct project/range loaded before trusting numbers.
- Form field names: `lead[from]`, `lead[to]`, `project[selected]` (element id `#project_selected`), `site_executive[picked]`, `refreshnow`.
- Column indices in each data row: Source = 0, Absolute Qualified = 9, Absolute Visit = 10.
- Values written to the sheet with a leading apostrophe to force text (protects slash values like "25/2" from date auto-conversion).
